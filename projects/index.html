    CanElevation Terrain Exporter

    Single-entry snapshot

    Single entry

    Problem Definition

    Exporting terrain for a specific area in Canada requires finding elevation tiles with sufficient coverage and preserving their elevation values and coordinate system.

    Problem Solution

    I built a Python desktop app that takes a bounding box from a map and checks coverage across Natural Resources Canada’s CanElevation STAC collections. Automatic selection picks the highest-resolution dataset with at least 99.5% estimated valid coverage. The exporter writes a Float32 GeoTIFF in the source collection’s metric coordinate system, a JSON record of the export, and optional hillshade and 16-bit heightmap previews.

    Minecraft Server Operations

    Single-entry snapshot

    Single entry

    Problem Definition

    Running community servers required reliable hosting and clear moderation during complex player disputes. Development of new engaging features was also needed to keep the community active and growing. The community also needed one place for guides, player pages, and tools that could deliver content into the game.

    Problem Solution

    I managed local and VPS deployments while handling moderation and conflict resolution to keep the community stable and active.
    I built the Mine & Craft wiki with Astro and combined Pagefind’s guide index with live player and coordinate listings. I integrated Discord sign-in and Minecraft username roles with a Cloudflare Worker so players can edit their own D1-backed pages, restore revisions, and manage media in R2.

A Python and FFmpeg bridge turns approved music submissions into Java and Bedrock sound packs for in-game disc claims and Copper Speakers playback. A Fabric companion handles claims for maps generated by the wiki’s image-to-map-art tool for Java and Bedrock accounts.

    Copper Speakers

    Single-entry snapshot

    Single entry

    Problem Definition

    I wanted Minecraft players to wire a jukebox to speakers and hear the same disc in multiple locations, including when the wiring changed during playback.

    Problem Solution

    I built a server-side Fabric mod that tracks the wiring as blocks change while preserving standard jukebox, hopper, and redstone behavior.
    To attach a speaker in the middle of a track, the server moves an already-playing sound source to it without starting the song again. Built-in discs share a decoded audio buffer to reduce startup differences between speakers. I instrumented Java client playback to measure timing and built a Geyser bundle with resource packs and mappings for Bedrock clients.
