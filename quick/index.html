    LoCapt: Local Live Captions

    Single-entry snapshot

    Single entry

    Problem Definition

    I wanted live captions for both sides of a conversation on Windows, including audio playing through the computer and speech picked up by the microphone.

    Problem Solution

    I built a Python desktop app that captures Windows system audio through WASAPI loopback alongside the microphone. Faster Whisper can transcribe either stream or translate it into English. When both sources are active, the app shows them in separate panes. After the model is downloaded, processing runs offline.
