    BeamNG.cad — From SolidWorks to a Tuned Vehicle

    Detailed project page
    Detailed

    Problem Definition

    As our Baja SAE vehicle designs evolve, rebuilding a simulation by hand takes time and specialist knowledge. Student turnover makes that expertise difficult to retain, so the workflow needs to be repeatable for future team members.

    Problem Solution

    I built a C# SolidWorks add-in with Python geometry, calibration, and vehicle-generation tools. The pipeline now produces a complete, drivable vehicle, with a well-tuned development build reached through iterative testing of its structure, suspension, steering, and drivetrain. Automated tests compare motion with the source CAD geometry; physical correlation with the real vehicle remains ongoing.
